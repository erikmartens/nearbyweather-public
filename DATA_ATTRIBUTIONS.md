# Additional Data Sources

NearbyWeather uses third-party data to support place search, observation station locations, and elevation. The following notices identify those sources and link to their terms or license information.

## GeoNames

Place names and geographic metadata contain data from [GeoNames](https://www.geonames.org/), available under the [Creative Commons Attribution 4.0 License](https://creativecommons.org/licenses/by/4.0/). NearbyWeather filters and organizes the source data for place search. These changes are not endorsed by GeoNames.

## Meteostat

Observation station names and locations contain data from the [Meteostat weather-stations project](https://github.com/meteostat/weather-stations), available under the [Creative Commons Attribution 4.0 License](https://creativecommons.org/licenses/by/4.0/). NearbyWeather filters and maps stations to searchable places. These changes are not endorsed by Meteostat.

## Additional Apple Weather Sources

Apple Weather uses additional data sources. See [Apple Weather data sources](https://developer.apple.com/weatherkit/data-source-attribution/) for the current source list and attribution details.

## Open-Meteo and Copernicus

Elevation information is provided through the [Open-Meteo Elevation API](https://open-meteo.com/en/docs/elevation-api) and is based on the Copernicus DEM. See the [Open-Meteo license](https://open-meteo.com/en/licence) and the [Copernicus DEM reference](https://doi.org/10.5270/ESA-c5d3d65).
