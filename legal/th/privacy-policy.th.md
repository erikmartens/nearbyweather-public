## 1. ภาพรวม
NearbyWeather เคารพความเป็นส่วนตัวของคุณ แอปได้รับการออกแบบมาเพื่อเก็บบุ๊กมาร์ก การตั้งค่า ข้อมูลสภาพอากาศที่แคชไว้ และปุ่มตัวเลือก API ไว้บนอุปกรณ์ของคุณ เว้นแต่คุณลักษณะที่เลือกไว้จำเป็นต้องสื่อสารกับสภาพอากาศ ตำแหน่ง การสนับสนุน หรือผู้ให้บริการรายงานข้อขัดข้อง

## 2. การรวบรวมข้อมูลและการจัดเก็บในตัวเครื่อง
NearbyWeather ไม่ได้ดำเนินการแบ็กเอนด์ของตัวเองสำหรับฟังก์ชันการทำงานของแอปปกติ แอปไม่ขายข้อมูลส่วนบุคคล ไม่ใช้ตัวระบุโฆษณา และไม่สร้างโปรไฟล์การโฆษณาหรือการติดตาม

แอพอาจจัดเก็บข้อมูลต่อไปนี้ไว้ในอุปกรณ์ของคุณ:

- บุ๊กมาร์กสถานีตรวจอากาศและบุ๊กมาร์กที่ถูกลบล่าสุด
- เลือกสถานที่ใกล้เคียง การค้นหา หน่วย การแจ้งเตือน ภาษา ลักษณะที่ปรากฏ และการตั้งค่าผู้ให้บริการสภาพอากาศ
- คีย์เสริม OpenWeather API ที่คุณป้อน
- ข้อมูลเมตาของสถานีตรวจอากาศที่แคชไว้ ข้อมูลสภาพอากาศ สถานะแผนที่ และข้อมูลเมตาของเว็บแคมที่จำเป็นในการแสดงเนื้อหาแอพและรองรับการใช้งานออฟไลน์
- การตั้งค่าการรายงานข้อขัดข้อง Firebase ที่เป็นตัวเลือก

ข้อมูลนี้จะยังคงอยู่ในอุปกรณ์ของคุณ เว้นแต่คุณสมบัติที่อธิบายไว้ด้านล่างจะส่งข้อมูลคำขอที่จำเป็นไปยังผู้ให้บริการบุคคลที่สาม

## 3. ข้อมูลตำแหน่งและสภาพอากาศ
หากคุณให้อนุญาตตำแหน่ง NearbyWeather จะใช้ตำแหน่งอุปกรณ์ของคุณเพื่อค้นหาสถานีตรวจอากาศใกล้เคียง แผนที่โฟกัส และขอข้อมูลสภาพอากาศสำหรับพิกัดที่เกี่ยวข้อง ขึ้นอยู่กับผู้ให้บริการสภาพอากาศและการตั้งค่าแอพที่คุณเลือก แอปอาจส่งพิกัด ตัวระบุสถานีตรวจอากาศ การตั้งค่าภาษา และคีย์ OpenWeather API ของคุณไปยังผู้ให้บริการสภาพอากาศหรือระดับความสูงภายนอก

NearbyWeather สามารถขอข้อมูลจาก Apple Weather / WeatherKit, OpenWeather, Open-Meteo และสภาพอากาศหรือแหล่งที่มาของการระบุแหล่งที่มาที่เกี่ยวข้อง ผู้ให้บริการเหล่านั้นดำเนินการตามคำขอภายใต้นโยบายความเป็นส่วนตัวและข้อกำหนดของตนเอง

## 4. การรายงานข้อขัดข้องและข้อผิดพลาด (ไม่บังคับ)
NearbyWeather ใช้ Google Firebase Crashlytics เพื่อรวบรวมรายงานข้อขัดข้องและการวินิจฉัยเฉพาะเมื่อเปิดใช้งานการรายงานข้อผิดพลาดเท่านั้น

รายงานข้อขัดข้องและการวินิจฉัยอาจรวมถึง:

- ประเภทอุปกรณ์และเวอร์ชันระบบปฏิบัติการ
- เวอร์ชันแอปและหมายเลขบิลด์
- ข้อมูลทางเทคนิคเกี่ยวกับเหตุการณ์ขัดข้องหรือการวินิจฉัย

NearbyWeather ไม่ได้ตั้งใจรวมบุ๊กมาร์กของคุณ คีย์ API หรือตำแหน่งที่แน่นอนในรายงานข้อขัดข้อง คุณสามารถปิดใช้งานการรายงานข้อผิดพลาดได้ตลอดเวลาในการตั้งค่าความเป็นส่วนตัวหรือวิธีใช้ของแอป

## 5. การแจ้งเตือน การรีเฟรชพื้นหลัง และป้ายไอคอนแอป
หากคุณเปิดใช้งานการแจ้งเตือนหรือป้ายอุณหภูมิไอคอนแอป NearbyWeather อาจรีเฟรชข้อมูลสภาพอากาศในพื้นหลังเพื่อให้ฟีเจอร์เหล่านั้นเป็นปัจจุบัน การตั้งค่าการแจ้งเตือนและการตั้งค่าป้ายสถานะจะถูกจัดเก็บไว้ในอุปกรณ์ของคุณ

## 6. เว็บแคมและลิงค์ภายนอก
NearbyWeather อาจแสดงรายการเว็บแคมใกล้เคียงและลิงก์ของผู้ให้บริการ การเปิดเว็บแคมหรือลิงก์ภายนอกอาจนำคุณไปยังเว็บไซต์หรือแอปของบุคคลที่สาม บริการของบุคคลที่สามเหล่านั้นอยู่นอกเหนือการควบคุมของ NearbyWeather และอยู่ภายใต้นโยบายความเป็นส่วนตัวของพวกเขาเอง

## 7. ไม่มีการติดตามหรือการโฆษณา
NearbyWeather ไม่ได้ใช้เทคโนโลยีการติดตาม ตัวระบุโฆษณา การวิเคราะห์โฆษณา หรือการจัดทำโปรไฟล์เพื่อวัตถุประสงค์ในการโฆษณา

## 8. ความปลอดภัย
ข้อมูลในเครื่องที่ละเอียดอ่อน รวมถึงคีย์ OpenWeather API ที่คุณป้อนจะยังคงอยู่ในอุปกรณ์ของคุณ คุณมีหน้าที่รับผิดชอบในการปกป้องอุปกรณ์ของคุณด้วยการรักษาความปลอดภัยระดับระบบ เช่น รหัสผ่าน Touch ID หรือ Face ID

## 9. การเก็บรักษาและการลบข้อมูล
คุณสามารถลบบุ๊กมาร์ก บุ๊กมาร์กที่ถูกลบล่าสุด และการตั้งค่าต่างๆ ผ่านแอพที่มีการควบคุมที่เกี่ยวข้อง คุณยังสามารถลบข้อมูลแอพทั้งหมดได้โดยการลบแอพออกจากอุปกรณ์ของคุณ ข้อมูลเมตาของสถานีตรวจอากาศที่มาพร้อมกับแอพเป็นส่วนหนึ่งของการติดตั้งแอพ

## 10. บริการของบุคคลที่สาม
NearbyWeather อาจโต้ตอบกับบริการของบุคคลที่สาม เช่น Apple Weather / WeatherKit, OpenWeather, Open-Meteo, Firebase Crashlytics, GitHub, บริการอีเมล และผู้ให้บริการเว็บแคม บริการเหล่านี้ไม่ได้ถูกควบคุมโดย NearbyWeather และนโยบายความเป็นส่วนตัวจะมีผลเมื่อคุณใช้คุณสมบัติที่ติดต่อกับพวกเขา

## 11. เด็ก ๆ
NearbyWeather ไม่ได้มุ่งเป้าไปที่เด็ก และไม่ได้รวบรวมข้อมูลส่วนบุคคลจากเด็กโดยเจตนา

## 12. การเปลี่ยนแปลง
