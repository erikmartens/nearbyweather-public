## 1. Επισκόπηση
Το NearbyWeather ("η εφαρμογή") παρέχει μια διεπαφή για κινητά για την ανακάλυψη μετεωρολογικών σταθμών, την προβολή καιρικών συνθηκών και προγνώσεων, τη διαχείριση σελιδοδεικτών, την προβολή χαρτών και κοντινών webcam και τη διαμόρφωση ειδοποιήσεων που σχετίζονται με τον καιρό και προτιμήσεων εφαρμογών.

## 2. Δεδομένα καιρού και υπηρεσίες τρίτων
Πληροφορίες καιρού, προβλέψεις, δεδομένα ποιότητας αέρα, δεδομένα υψομέτρου, μεταδεδομένα σταθμού, μεταδεδομένα κάμερας web και εξωτερικοί σύνδεσμοι ενδέχεται να προέρχονται από τρίτους παρόχους όπως οι Apple Weather / WeatherKit, OpenWeather, Open-Meteo και πάροχοι κάμερας web.

Το NearbyWeather δεν συνδέεται, δεν υποστηρίζεται από ή δεν είναι υπεύθυνο για αυτούς τους τρίτους παρόχους, εκτός εάν αναφέρεται ρητά. Η διαθεσιμότητα δεδομένων, η ακρίβεια, οι όροι αδειοδότησης και η συμπεριφορά υπηρεσίας είναι εκτός του ελέγχου της εφαρμογής.

## 3. Ευθύνη χρήστη
Χρησιμοποιώντας την εφαρμογή, συμφωνείτε ότι:

- θα χρησιμοποιείτε μόνο δεδομένα καιρού ως ενημερωτική καθοδήγηση
- δεν θα βασίζεστε στην εφαρμογή για κρίσιμες αποφάσεις για την ασφάλεια, έκτακτη ανάγκη, αεροπορικές, θαλάσσιες, ιατρικές ή άλλες αποφάσεις υψηλού κινδύνου
- είστε υπεύθυνοι για τα κλειδιά API, τους λογαριασμούς παρόχου, τις επιλογές ειδοποιήσεων και τους σελιδοδείκτες που διαμορφώνετε
- δεν θα χρησιμοποιήσετε την εφαρμογή ή οποιαδήποτε συνδεδεμένη υπηρεσία παρόχου με τρόπο που παραβιάζει την ισχύουσα νομοθεσία ή τους όρους του παρόχου

## 4. Τοποθεσία, ειδοποιήσεις και λειτουργία παρασκηνίου
Ορισμένες λειτουργίες απαιτούν άδεια τοποθεσίας, άδεια ειδοποίησης ή ανανέωση φόντου. Μπορείτε να διαχειριστείτε αυτά τα δικαιώματα στις ρυθμίσεις iOS. Εάν τα δικαιώματα ή η πρόσβαση στο δίκτυο δεν είναι διαθέσιμα, οι σχετικές λειτουργίες ενδέχεται να είναι περιορισμένες ή μη διαθέσιμες.

## 5. Κλειδιά OpenWeather API
Εάν επιλέξετε να χρησιμοποιήσετε λειτουργίες OpenWeather που απαιτούν το δικό σας κλειδί API, είστε υπεύθυνοι για τη λήψη, την εισαγωγή, την ασφάλεια και τη συμμόρφωση με τους όρους που ισχύουν για αυτό το κλειδί. Το NearbyWeather αποθηκεύει το κλειδί τοπικά στη συσκευή σας και το χρησιμοποιεί μόνο για αιτήματα OpenWeather που ξεκινούν από τη λειτουργικότητα της εφαρμογής.

## 6. Εξωτερικοί σύνδεσμοι και κάμερες web
Η εφαρμογή μπορεί να ανοίγει ιστότοπους, σελίδες υποστήριξης, σελίδες απόδοσης παρόχου, σελίδες webcam, σελίδες τεύχους GitHub ή προγράμματα-πελάτες ηλεκτρονικού ταχυδρομείου. Το NearbyWeather δεν ευθύνεται για το περιεχόμενο, τη διαθεσιμότητα, τις πρακτικές απορρήτου ή τους όρους των εξωτερικών υπηρεσιών.

## 7. Χωρίς εγγύηση
Η εφαρμογή παρέχεται "ως έχει" χωρίς κανενός είδους εγγυήσεις. Δεν εγγυόμαστε:

- αδιάλειπτη διαθεσιμότητα
- Λειτουργία χωρίς σφάλματα
- συμβατότητα με κάθε συσκευή, έκδοση iOS, λογαριασμό παρόχου ή κλειδί API
- ορθότητα, φρεσκάδα ή πληρότητα δεδομένων καιρού, πρόγνωσης, ποιότητας αέρα, υψομέτρου, σταθμού, χάρτη ή κάμερας web τρίτων

- προβλήματα δικτύου, παρόχου, συσκευής, άδειας ή διαμόρφωσης
- απώλεια σελιδοδεικτών, προτιμήσεων, αποθηκευμένων δεδομένων ή κλειδιών API
- χρήση της εφαρμογής σε κρίσιμες για την ασφάλεια καταστάσεις ή καταστάσεις υψηλού κινδύνου
- εξωτερικοί ιστότοποι, πάροχοι κάμερας web, εργαλεία υποστήριξης ή υπηρεσίες τρίτων
