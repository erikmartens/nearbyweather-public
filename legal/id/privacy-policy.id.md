## 1. Ikhtisar
NearbyWeather menghormati privasi Anda. Aplikasi ini dirancang untuk menyimpan bookmark, preferensi, data cuaca dalam cache, dan kunci API opsional di perangkat Anda kecuali fitur yang dipilih perlu berkomunikasi dengan penyedia cuaca, lokasi, dukungan, atau pelaporan kerusakan.

## 2. Pengumpulan Data dan Penyimpanan Lokal
NearbyWeather tidak mengoperasikan backendnya sendiri untuk fungsionalitas aplikasi normal. Aplikasi tidak menjual data pribadi, tidak menggunakan pengidentifikasi iklan, dan tidak membuat profil periklanan atau pelacakan.

Aplikasi dapat menyimpan informasi berikut secara lokal di perangkat Anda:

- stasiun cuaca yang ditandai dan bookmark yang baru saja dihapus
- Dipilih di sekitar, pencarian, unit, notifikasi, bahasa, tampilan, dan preferensi penyedia cuaca
- kunci OpenWeather API opsional yang Anda masukkan
- Metadata stasiun cuaca dalam cache, data cuaca, status peta, dan metadata webcam yang diperlukan untuk menampilkan konten aplikasi dan mendukung penggunaan offline
- preferensi pelaporan kerusakan Firebase opsional

Data ini tetap ada di perangkat Anda kecuali fitur yang dijelaskan di bawah mengirimkan data permintaan yang diperlukan ke penyedia pihak ketiga.

## 3. Data Lokasi dan Cuaca
Jika Anda memberikan izin lokasi, NearbyWeather menggunakan lokasi perangkat Anda untuk menemukan stasiun cuaca terdekat, memfokuskan peta, dan meminta data cuaca untuk koordinat yang relevan. Tergantung pada penyedia cuaca dan pengaturan aplikasi yang Anda pilih, Aplikasi dapat mengirimkan koordinat, pengidentifikasi stasiun cuaca, preferensi bahasa, dan kunci OpenWeather API Anda ke penyedia cuaca atau ketinggian eksternal.

NearbyWeather dapat meminta data dari Apple Weather / WeatherKit, OpenWeather, Open-Meteo, dan sumber cuaca atau atribusi terkait. Penyedia tersebut memproses permintaan berdasarkan kebijakan dan ketentuan privasi mereka sendiri.

## 4. Pelaporan Kerusakan dan Kesalahan (Opsional)
NearbyWeather menggunakan Google Firebase Crashlytics untuk mengumpulkan laporan kerusakan dan diagnostik hanya jika pelaporan kesalahan diaktifkan.

Laporan kerusakan dan diagnostik mungkin mencakup:

- jenis perangkat dan versi sistem operasi
- versi aplikasi dan nomor build
- informasi teknis tentang kecelakaan atau kejadian diagnostik

NearbyWeather tidak sengaja menyertakan bookmark, kunci API, atau lokasi persis Anda dalam laporan kerusakan. Anda dapat menonaktifkan pelaporan kesalahan kapan saja di pengaturan privasi atau bantuan Aplikasi.

## 5. Notifikasi, Penyegaran Latar Belakang, dan Lencana Ikon Aplikasi
Jika Anda mengaktifkan notifikasi atau lencana suhu ikon aplikasi, NearbyWeather dapat menyegarkan informasi cuaca di latar belakang sehingga fitur tersebut tetap terkini. Preferensi pemberitahuan dan pengaturan lencana disimpan secara lokal di perangkat Anda.

## 6. Webcam dan Tautan Eksternal
NearbyWeather mungkin menampilkan entri webcam terdekat dan tautan penyedia. Membuka webcam atau tautan eksternal mungkin membawa Anda ke situs web atau aplikasi pihak ketiga. Layanan pihak ketiga tersebut berada di luar kendali NearbyWeather dan diatur oleh kebijakan privasi mereka sendiri.

## 7. Tidak Ada Pelacakan atau Iklan
NearbyWeather tidak menggunakan teknologi pelacakan, pengidentifikasi iklan, analisis periklanan, atau pembuatan profil untuk tujuan periklanan.

## 8. Keamanan
Data lokal sensitif, termasuk kunci OpenWeather API yang Anda masukkan, tetap ada di perangkat Anda. Anda bertanggung jawab untuk melindungi perangkat Anda dengan keamanan tingkat sistem seperti kode sandi, Touch ID, atau Face ID.

## 9. Penyimpanan dan Penghapusan Data
Anda dapat menghapus bookmark, bookmark yang baru saja dihapus, dan preferensi melalui Aplikasi di mana kontrol yang relevan tersedia. Anda juga dapat menghapus semua data aplikasi dengan menghapus Aplikasi dari perangkat Anda. Metadata stasiun cuaca yang dibundel dengan Aplikasi adalah bagian dari instalasi Aplikasi.

## 10. Layanan Pihak Ketiga
NearbyWeather dapat berinteraksi dengan layanan pihak ketiga seperti Apple Weather / WeatherKit, OpenWeather, Open-Meteo, Firebase Crashlytics, GitHub, layanan email, dan penyedia webcam. Layanan ini tidak dikontrol oleh NearbyWeather, dan kebijakan privasinya sendiri berlaku saat Anda menggunakan fitur yang menghubungi mereka.

## 11. Anak-anak
NearbyWeather tidak ditujukan untuk anak-anak dan tidak dengan sengaja mengumpulkan data pribadi dari anak-anak.

## 12. Perubahan
Kebijakan Privasi ini mungkin diperbarui di masa mendatang. Perubahan akan tercermin dalam Aplikasi dan dokumen hukum publik.
